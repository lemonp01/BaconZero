# BaconZero
BaconZero is a portable low-power embedded wireless experimentation platform designed for learning embedded systems, RF communication, and hardware security concepts through hands-on development.

Inspired by handheld multi-tool devices ( such as Flipper Zero), BaconZero focuses on modular hardware, efficient firmware design, and practical wireless experimentation in a compact form factor.

## Stage 1 Features

The first development stage focuses on integrating:

- RFID / NFC interaction
- Sub-GHz communication using Texas Instruments CC1101
- Infrared transmit and receive capabilities
- Battery-powered portable operation
- RTOS-based embedded firmware architecture

## Project Goals

BaconZero is built as a learning platform for exploring:

- Embedded firmware development
- Low-power system design
- RF communication protocols
- Infrared communication systems
- Signal analysis and packet experimentation
- Custom PCB design
- Portable hardware product development

## Planned Hardware Architecture
```
MCU
├── RFID / NFC
├── CC1101 RF Module
├── Infrared TX/RX
├── Display & Input
├── Battery Management
└── Expandable Interfaces
```

## Future Plans

BaconZero is intended for educational purposes, interoperability testing, and authorized security research only. Users are responsible for complying with local laws and regulations regarding wireless communication and signal transmission.
